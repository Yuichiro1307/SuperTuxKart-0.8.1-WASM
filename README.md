# SuperTuxKart-0.8.1-WASM
This is a project to port SuperTuxKart 0.8.1 to WASM so it can be played on the web. Since this is a personal project, please don't set your expectations too high!
The initial goal is to get it working on Chromium-based browsers. I plan to add support for Firefox once it is operational on Chromium-based browsers.
This project is scheduled for completion by 2028.
If possible, we are also considering creating an offline version that you can download and run on your computer. Please stay tuned!
# Note: This project was created by a Japanese developer. Please be aware that there may be imperfect English in various places, including the README.
